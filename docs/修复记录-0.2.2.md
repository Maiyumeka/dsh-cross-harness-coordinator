# 0.2.2：结束已完成的单个任务

0.2.1 的“结束此任务”只显示在未完成任务上。实际界面里的三个任务都已审查通过，按钮因此被隐藏；不是安装包里缺少按钮代码。

0.2.2 为已通过、已失败、无法验证和已取消任务也显示“结束此任务”。确认后，该任务移出当前列表并进入“已结束任务”区；产物文件、原任务状态、结果版本、审查及执行历史保留。界面可以查看记录和现有产物；更早计划的记录也保留并可展开。此操作不会把 passed 改为 cancelled，不会启动模型或重新派发工作。

未完成任务继续使用单任务 cancel；已完成任务使用新的 coordinator_control action=close、id=任务编号。工具和设置 RPC 同时支持，close 不允许用来跳过未完成工作。所有操作仍绑定当前会话，切换会话时旧的确认窗口和异步查询不会应用到新会话。

内部保留依赖关系：已结束的前置仍可供当前任务核对和执行。如果前置产物发生变化且仍有当前任务依赖它，原审查会按既有规则失效并重新出现在当前列表；没有当前工作引用的已结束历史不会自动恢复执行。新计划保存旧记录并清除复制过来的关闭标记，已结束记录不会永久锁住执行端移除。

验证包括 task-history.mjs 的真实产物、审查记录、重启、新计划和依赖回归，以及 defects-ui.mjs 中已通过任务的实际浏览器按钮、确认、历史与产物查看。测试使用隔离数据，不关闭用户现有的三个任务。
