## 宿主升级隔离

插件使用普通 bundle 注册。超出兼容范围时，宿主的 loadProfileDirectory 将其列入 skippedBundles，其余正常 bundle 继续组装。候选包不包含安装、卸载、迁移或宿主升级生命周期脚本，不修改宿主可执行文件。安装预检对发布清单中的精确验收版本做保守核对。

隔离探针使用本机 app.asar 的复制运行树及真实 dsh-app-boot 加载器，覆盖正常候选包、不兼容旧候选包和缺失包共存时的加载、配置字节保持和其余条目继续组装。未来版本测试依据当前加载器的兼容策略，未来宿主自身的加载器变更需要再次核对。

## 复现

将现役 app.asar 内的 dsh 运行树复制到隔离目录，并将 COORDINATOR_HOST_RUNTIME 设为该目录。所有测试数据写入 test-data。

```powershell
node scripts/build-runtime.mjs
npm pack --ignore-scripts --pack-destination dist
# 设置 DSH_HOME、COORDINATOR_DSH_CLI、COORDINATOR_DSH_ASAR 后生成发布清单
node scripts/release.mjs
node --loader ./test/host-runtime-loader.mjs test/host-update-smoke.mjs
node --loader ./test/host-runtime-loader.mjs test/run.mjs
```

探针包含真实工具定义注册、设置 RPC、冷会话读取及释放、客户端设置页渲染和清理。核心套件另覆盖本地协议进程、任务与产物状态、审批、MCP、Codex 等夹具。用户已确认正式桌面验收完成，测试通过。
